## 🚀 Proyecto destacado
- 🏋️ PowerGym – Plataforma Web de Gestión de Centro de Entrenamiento
- Como parte de un equipo de múltiples disciplinas, colaboré en el desarrollo de una aplicación web para gestión de un gimnasio, en autenticación de usuarios (usuario, coach o administrador) donde la funcionalidad cambia dependiendo del rol. 
- El enfoque principal es para brindar una gran experiencia al usuario desde crear su cuenta, explorar las clases ofertadas, comprar membresias y agendar clases.
- Mi enfoque de desarrollo es backend, ocupando de la parte "mas dura" de lógica siendo las clases, su agendamiento y reservación del usuario. Logrando asi una lógica consistente y, de ser necesario, escalable a necesidad del cliente.

• Desarrollo de backend con TypeScript, NestJS y JWT.
• Diseño de lógica de negocio.
• Coordinación con el equipo frontend para la correcta integración y modificaciones.

- ⚛ Tecnologias utilizadas: Stripe, NestJS, TypeScript, JSON Web Token (JWT), TypeORM, PostgreSQL, Cloudinary, API de Swagger, Jest, Docker, GitHub Actions
