## 🚀 Featured Project
🏋️ PowerGym – Training Center Management Web Platform
As part of a multidisciplinary team, I collaborated on developing a web application for gym management, specifically working on user authentication (User, Coach, or Admin roles) where core features dynamically change based on the assigned role.
The primary focus is to deliver an outstanding user experience, covering everything from account creation and exploring scheduled classes to purchasing memberships and booking slots.
My development focus was on the backend, handling the core "heavy lifting" logic for classes, scheduling pipelines, and user reservations. This resulted in a robust, consistent, and highly scalable logic architecture tailored to client needs.

• Backend development using TypeScript, NestJS, and JWT.
• Core business logic design.
• Close coordination with the frontend team for seamless API integration and adjustments.

⚛ Technologies used: Stripe, NestJS, TypeScript, JSON Web Token (JWT), TypeORM, PostgreSQL, Cloudinary, Swagger API, Jest, Docker, GitHub Actions.
